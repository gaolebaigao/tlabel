# Demo Data

These datasets are **synthetically generated** for demonstration purposes only.
They simulate grasp-hold-release episodes with realistic-looking but algorithmically
produced feature values, so you can try `tlabel.demo()` without any real sensor data.

**⚠️ Not measured data.** Do not use these files for benchmarking, training, or
scientific evaluation. For real-world datasets, see our
[supported sensors](https://github.com/liesliy/tlabel#-supported-sensors) and
[public dataset guide](https://github.com/liesliy/tlabel#data-sources).

| File | Sensor | Frames | Duration |
|------|--------|:------:|:--------:|
| `demo_gelsight.json` | GelSight Mini | 150 | 5.0 s |
| `demo_digit.json` | DIGIT | 100 | 3.3 s |
| `demo_paxini.json` | PaXini PXCap | 120 | 4.0 s |
| `demo_daimon.json` | Daimon DM-TacClaw | 80 | 3.2 s |
