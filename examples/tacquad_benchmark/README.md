# TacQuad Benchmark: Cross-Sensor Tactile Annotation Evaluation

## Overview

We evaluate **TLabel Format** on the **TacQuad dataset** (4 sensors, 3 scenarios, 104K frames) to validate cross-sensor generalization of semantic annotations.

## Dataset

| Property | Value |
|----------|-------|
| Total Episodes | 671 |
| Total Frames | 104,576 |
| Sensors | GelSight, DIGIT, DuraGel, Tac3D |
| Scenes | Fine, Indoor, Outdoor |
| Features | 17-dim (TLabel Format) |

## Experiment Design

### Downstream Tasks
We evaluate TLabel features on 4 representative tactile tasks:
- **Contact Detection**: Binary classification (contact/no-contact)
- **Slip Detection**: Binary classification (slip/no-slip)
- **Force Prediction**: Regression (force magnitude)
- **Grasp Phase Recognition**: 7-class classification (light_contact, stable_grasp, no_contact, slipping, heavy_press, holding, transition)

### Evaluation Protocol
- 5-fold Cross-Validation
- Models: Logistic Regression, Ridge Regression, Random Forest
- Metrics: Accuracy, F1-score, R², RMSE

## Results

### Downstream Evaluation (5-fold CV, 104,576 samples × 17-dim features)

| Task | Ridge/LR | Random Forest |
|------|----------|---------------|
| Contact | Acc=1.0, F1=1.0 | Acc=1.0, F1=1.0 |
| Slip | Acc=0.998, F1=0.998 | Acc=1.0, F1=1.0 |
| Force | R²=0.185, RMSE=2.063 | R²=0.826, RMSE=0.955 |
| Phase | Acc=0.945, F1=0.939 | Acc=0.9997, F1=0.9997 |

### Cross-Sensor Generalization (Fine Scene)

| Task | Intra-Family R² (RF) | Cross-Family R² (RF) |
|------|---------------------|---------------------|
| Force | -0.26 ± 0.52 | -1.58 ± 0.79 |

**Contact Detection**: Acc=1.0 for ALL sensor pairs, including cross-family (GS↔Tac3D).

### Ablation Study: Key Feature Importance

| Task | Most Important Feature | Importance |
|------|----------------------|------------|
| Slip | slip_entropy | 0.200 |
| Force | deformation_magnitude | 0.791 |
| Phase | slip_entropy | 0.098 (drop) |

## Key Findings

1. **Semantic labels (contact/slip/phase) generalize perfectly across sensors**, while force prediction remains sensor-specific. This validates that TLabel annotations capture abstract tactile concepts rather than sensor-specific signals.

2. **slip_entropy is the single most critical feature for slip detection** (importance=0.200), while all other features contribute near-zero importance (~0.000). This reveals a fundamental property of tactile slip: it is best detected through entropy-based uncertainty measures.

3. **TLabel features have clear task-specific physical meanings**: slip_entropy for slip/phase detection, deformation_magnitude for force prediction (importance=0.791). This interpretability supports debugging and domain adaptation.

## Data Format

Input data is generated by **TLabel** (`pip install tlabel`) and stored as JSON files:
```
tlabel_output/
├── fine/
│   ├── cube/
│   │   ├── gelsight.json
│   │   ├── digit.json
│   │   ├── duragel.json
│   │   └── tac3d.json
│   └── ...
├── indoor/
└── outdoor/
```

Each JSON contains:
- `annotations`: 17 TLabel features per frame
- `ground_truth`: force measurements and semantic labels
